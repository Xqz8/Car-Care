# CarCare - Vehicle Expense Tracker App

CarCare is an Android app that helps you track your vehicle expenses, maintenance schedules, and fuel logs.

## Features
- Track vehicle expenses
- Preventive Maintenance Schedule (PMS) reminders
- Fuel log tracking
- Expense analytics
- Multi-vehicle support

## How to Install

1. Go to the [Releases](https://github.com/Xqz8/Car-Care/releases) page
2. Download the latest `app-release.apk` file
3. On your Android phone, enable **Install from unknown sources**:
   - Settings → Apps → Special app access → Install unknown apps
4. Open the downloaded APK file and tap **Install**

## Requirements
- Android 6.0 (API level 23) or higher
